# 已上線遊戲：玩法與家長說明初步檢查

範圍：依 `packages/game-core` 可玩清單，檢視十二款遊戲的規則程式與現有說明。這是靜態設計檢查，並非十二款完整的實機遊玩、兒童測試或學習成效研究。下表的技能為玩法提供的練習機會，不保證能力提升。提出的問題要經實玩與測試確認，再以每款獨立 PR 改版。

| 遊戲 | 操作與可向家長說明的練習機會 | 已見證據與優先檢查 |
| --- | --- | --- |
| G001 完美疊塔 | 看移動的方塊並選時機放下：視覺判斷、專注、手眼協調。 | 有兒童慢速模式與命中寬容度；實玩檢查高層加速與恢復規則是否易懂、失敗是否公平。 |
| G002 九九乘法怪獸塔 | 回答乘法：乘法熟悉度、辨認答案、錯後再嘗試。 | 90秒限時；驗證錯題回饋與復習是否讓孩子理解，而非只催促作答；評估更從容的練習選項。 |
| G003 顏色實驗室 | 分類與倒水：分類、步驟規劃與耐心試錯。 | 規則已有求解器、撤銷及星等；檢查顏色以外的辨識方式、提示與星等對初學者是否友善。 |
| G004 學科跑酷王 | 選路答數學或英文題並避障：學科練習、注意分配、操作反應。 | 數學為程序生成，英文各年級題庫各8題；檢查題目重複、答案出現時機、題目與障礙同時出現是否公平，避免稱反應訓練必然遷移到生活。 |
| G006 影子變變變 | 旋轉輪廓：形狀辨識、方向與嘗試。 | 規則目前3個固定題；實玩確認對稱形狀的合法方向與畫面一致，評估增加題型及更有意義的解法。 |
| G007 節奏花園 | 聆聽並重複音符順序：聆聽、順序記憶與操作配合。 | 目前3段固定序列，規則不考核節奏時間；應檢查名稱和文案是否讓人誤以為要按節拍，評估新增可選節奏玩法及靜音可玩提示。 |
| G008 紙飛機郵差 | 調角度並觀察風與落點：預測、比較和調整。 | 目前3條固定路線，使用拋體簡化模型；檢查風向和落點回饋是否可理解，明示非真實紙飛機模擬，評估更豐富路線。 |
| G009 小小造橋師 | 建造與測試：觀察、規劃、比較並修改。 | 已確認兩岸支點未清晰表現、3關變化不足；重新設計提案待實作與求解驗證。 |
| G018 雲朵捏捏樂 | 拖動輪廓並加貼紙：形狀探索、想像和手眼協調。 | 自由創作不應被強制闖關取代；檢查拖動與鍵盤等替代操作，及創作流程是否適合學齡前兒童。 |
| G019 雙人小島任務 | 兩人輪流走路、開橋與找寶石：輪流、路線觀察與交流。 | 目前2張固定地圖；兩側的開關和橋各自對應，需實玩判斷是否真正需要兩人協作，評估更多互相幫助的設計。 |
| C001 小島佔地王 | 鋪路和圍地：空間推理、策略與輪流。 | 圍地計算以被佔格及岩石阻擋空格連通為基礎，觸發需要至少一個己方道路連結；需用具體棋局核對圖形與規則說明，避免玩家誤以為封閉路線必須全由自己道路構成。重新驗證先手與AI平衡。 |
| C002 記憶怪獸翻翻樂 | 找相同圖卡：圖像記憶、配對與輪流觀察。 | 程式的語音素材目前僅繁體中文；此前九語均宣稱全程可聽、不需識字，與實作不符。修正家長說明，並另行驗收其他語言的可用性與學齡前流程。 |

## 後續每款改版的驗收標準

1. 開始前以玩家實際操作說明1–3項可練習技能，九語與遊戲內容一致，不宣稱治療或保證提高成績；不以閱讀障礙、能力程度等特質做推論。
2. 規則、畫面與提示一致；確認失敗原因與可行下一步，不用無提示的隱藏規則。
3. 用引導、適量變化及公平可調的難度建立挑戰；兒童觀察結果與設計假設分開記錄。
4. 對照手機、平板、桌機、折疊裝置與鍵盤操作；含九語、RTL、回首頁、分享與音訊檢查。瀏覽器模擬與實機測試分別註明。
5. 一款一分支與 PR：自動檢查、可玩預覽、375×812及800×600截圖，回報後再合併部署。無後端、帳號與公開排行榜。
