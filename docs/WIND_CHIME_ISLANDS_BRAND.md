# 朵朵的風鈴群島：角色與品牌初稿

一座由小島、森林與夜空串成的溫柔冒險世界。孩子和朋友一起觀察、試驗、出錯、再嘗試；每款遊戲仍保留自己鮮明的美術與玩法。

- **朵朵 Dodo**：藍色小狗，勇敢好奇，葉形耳朵、月牙與綠色披肩；帶孩子跨出第一步。
- **栗栗 Lili**：橘色松鼠，細心溫暖，圍巾和圍裙；擅長準備、分類與照顧朋友。
- **小燈 Pip**：奶金色小貓頭鷹，星形羽冠、青綠圍巾；喜歡觀察夜空，給孩子提示但不代替思考。

## 動作與表現

本次遊戲先實作可重用的靜態角色素材與CSS動作狀態：呼吸與輕晃（等待）、傾身（提示或嘗試）、跳躍搖擺（完成）。動作不遮擋操作，尊重減少動態效果設定；動作以外仍有文字及明確狀態，靜音也可玩。往後可擴充逐格動作：走跑、抬手、拿物、思考、指引、鼓勵及雙人互動；需依遊戲需求製作獨立姿勢，不把旋轉圖片誤稱為完整角色動畫。

角色圖片為本專案創作，獨立遊戲各自帶入靜態素材，離線可用。小燈初稿以朵朵與栗栗既有角色圖為參考生成，經轉換為透明WebP。各語系的人名與語氣需在正式品牌擴張前經母語者檢查；名稱、字標及商標可用性尚未完成法律檢索。
