# 20款遊戲：玩法差異與兒童遊玩驗收

更新：2026-10-25。20款是產品目標；目前只有G001、G002可玩。企劃名稱、玩法及順序會依兒童實測調整。

## 參考與取捨

- [4388全部遊戲分類](https://4388.fun/c/all)提供料理、益智、音樂節奏、棋牌桌遊、模擬經營、冒險解謎等玩法樣本。2026-10-25檢視分類與部分列表；榜單排名、評分及數量會變，這裡只借鏡互動類型，不依評分判斷兒童喜好。
- [UNICEF Innocenti的RITEC研究](https://www.unicef.org/innocenti/projects/responsible-innovation-technology-children)指出兒童數位遊玩可支持自主選擇、掌握挑戰、創作、探索與連結，效果因兒童及情境而異。因此20款會分配到手感、解謎、創作、探索與同玩，不把答題計時複製成20種外觀。
- [美國心理學會的兒童學習建議](https://www.apa.org/education-career/k12/top-ten-principles-families)建議挑戰略高於既有能力，並提醒過度依賴外部獎勵可能削弱原本的興趣。讓玩家看懂進步、選擇下個小目標；不靠連續登入、錯過就失去獎勵或無止境抽獎推動回流。
- 操作目標以大而分開的觸控區優先；[WCAG 2.2點擊目標最低尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)為24×24 CSS像素且有例外，本站遊戲主操作設計目標提高到至少44×44 CSS像素，並支援鍵盤、減少動態效果、音效開關與足夠對比。實際裝置仍須驗收。

| 參考分類 | 可借鏡的感受 | Game Lab變形方向 | 首個候選 |

| 益智 | 每次嘗試得到新線索 | 試管排序加可撤銷及多解；影子旋轉、指令迷宮提供不同思考方式 | G003、G006、G012 |

| 棋牌桌遊 | 輪流規劃、路線取捨 | 小島送信棋以短路線及可預測事件為核心，不做賭博或抽卡付費 | G015小島郵差棋 |

## 每款上線前的遊玩驗收

1. 用一句話講出「我現在要做什麼」；首次接觸不需長教學就能完成第一個動作。
2. 前20秒得到能理解的回饋；成功有聲畫回應，失敗給下一次能嘗試的提示。音效預設關閉，動態可減少。
3. 難度由玩家能力漸增，提供練習或較慢選項；不得把答錯直接變成羞辱、付費或永久損失。
4. 有一個主要重玩目標，但不同遊戲要分別依賴技巧、解法、創作或探索。結算可分享成績／作品，也能立即重玩。
5. 手機、平板、桌機及折疊裝置版面可操作；9種語言與RTL排版、長字串、本地口語需逐款測試。低階手機離線遊玩及長時間發熱要實測。
6. 先觀察不同年齡兒童與照顧者實際遊玩：是否理解、是否笑／想再試、卡在哪裡、是否自主停止。紀錄可用不蒐集姓名的匿名觀察表；數字目標在有樣本後再定。

## 發行順序

先完成G003《顏色實驗室》以補足非計時解謎，再選一款創作類與一款手感類做小規模玩家測試。後續按照「玩法與現有作品差異、手機性能、兒童理解、製作成本」排序，不為了湊20款而發布半成品。

## 本地模型使用決定

本機已安裝Ollama與`gpt-oss:20b`。2026-10-25用短企劃提示試跑，冷啟動超過50秒仍未產出，因此這輪直接由人工檢視分類並完成企劃。日後可在模型已啟動時用於批次發想關卡草稿或檢查文案重複度；規則正確性、適齡性、母語用法與上線品質仍由程式測試及實際玩家驗收。遊戲執行時不依賴本地或雲端模型。
