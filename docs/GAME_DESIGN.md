# 20款遊戲：玩法差異與兒童遊玩驗收

更新：2026-10-25。20款是產品目標；目前G001、G002、G003可玩。企劃名稱、玩法及順序會依兒童實測調整。

## 參考與取捨

- [4388全部遊戲分類](https://4388.fun/c/all)提供料理、益智、音樂節奏、棋牌桌遊、模擬經營、冒險解謎等玩法樣本。2026-10-25檢視分類與部分列表；榜單排名、評分及數量會變，這裡只借鏡互動類型，不依評分判斷兒童喜好。
- [UNICEF Innocenti的RITEC研究](https://www.unicef.org/innocenti/projects/responsible-innovation-technology-children)指出兒童數位遊玩可支持自主選擇、掌握挑戰、創作、探索與連結，效果因兒童及情境而異。因此20款會分配到手感、解謎、創作、探索與同玩，不把答題計時複製成20種外觀。
- [美國心理學會的兒童學習建議](https://www.apa.org/education-career/k12/top-ten-principles-families)建議挑戰略高於既有能力，並提醒過度依賴外部獎勵可能削弱原本的興趣。讓玩家看懂進步、選擇下個小目標；不靠連續登入、錯過就失去獎勵或無止境抽獎推動回流。
- 操作目標以大而分開的觸控區優先；[WCAG 2.2點擊目標最低尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)為24×24 CSS像素且有例外，本站遊戲主操作設計目標提高到至少44×44 CSS像素，並支援鍵盤、減少動態效果、音效開關與足夠對比。實際裝置仍須驗收。

## 每款上線前的遊玩驗收

1. 用一句話講出「我現在要做什麼」；首次接觸不需長教學就能完成第一個動作。
2. 前20秒得到能理解的回饋；成功有聲畫回應，失敗給下一次能嘗試的提示。音效、配音、配樂預設開啟並可一鍵關閉（見[AUDIO.md](AUDIO.md)），動態可減少。
3. 難度由玩家能力漸增，提供練習或較慢選項；不得把答錯直接變成羞辱、付費或永久損失。
4. 有一個主要重玩目標，但不同遊戲要分別依賴技巧、解法、創作或探索。結算可分享成績／作品，也能立即重玩。
5. 手機、平板、桌機及折疊裝置版面可操作；9種語言與RTL排版、長字串、本地口語需逐款測試。低階手機離線遊玩及長時間發熱要實測。
6. 先觀察不同年齡兒童與照顧者實際遊玩：是否理解、是否笑／想再試、卡在哪裡、是否自主停止。紀錄可用不蒐集姓名的匿名觀察表；數字目標在有樣本後再定。

## 設計建議（2026-10-25 Claude評估，待Codex實作）

以下7點為待實作項目。第2點的玩法合併只是**候選**，上方企劃矩陣先不刪改，等兒童實測與Justin確認後再調整。

### 1. 共同世界觀與陪玩角色

20款各自獨立，玩完就結束，缺少陪伴感。G002（怪獸塔）、G010（小怪獸心情）已經有怪獸元素，建議統一成「怪獸島」：

- Portal首頁從卡片列表改成島嶼地圖，每款遊戲是島上一個地點；未開放的地點以霧或施工中呈現。
- 一隻固定的陪玩小怪獸出現在每款遊戲，負責稱讚與提示；配音（見[AUDIO.md](AUDIO.md)）由同一角色、同一聲音說出。
- 跨遊戲收集貼紙或小怪獸裝扮，只給外觀獎勵；不做連續登入、限時領取或抽獎。
- 角色與世界觀做成共用套件或素材包，各遊戲引用，不各自重畫。

### 2. 玩法重疊（合併候選，待實測決定）

| 重疊組合 | 問題 | 候選處理 |
| --- | --- | --- |
| G002乘法怪獸塔、G004算術跑酷王 | 都是限時算術 | 保留一款，另一款改為記憶或觀察類 |
| G008紙飛機郵差、G015小島郵差棋 | 題材都是郵差 | 其中一款換題材 |
| G008紙飛機、G009造橋、G016磁力 | 三款都是物理操作 | 保留兩款 |
| G012機器人迷宮、G015郵差棋 | 都是排路線、少步數 | 拉開機制差異，或合併 |
| G014螢火蟲小花園、G020口袋星球 | 都是配置生態、觀察結果 | 保留一款 |

空出的名額候選補現有缺口：塗鴉著色（學齡前可玩）、觀察找東西／找不同、分類與配對（4–6歲）、怪獸捏捏（自組角色，可帶進其他遊戲）。

### 3. 年齡分段

「兒童」範圍太廣。每款在企劃與Portal標示主要年齡層，並依年齡層套用設計限制：

- **4–6歲（學齡前、未識字）**：全程圖示與配音引導，不需閱讀；失敗不結束一局；操作只用點擊與拖曳。
- **7–9歲**：可加入簡單數學、文字與規劃。
- **10歲以上與大人**：困難模式、追分數、每日挑戰。

配音因此是學齡前遊戲的必要條件，不能只顯示文字。

### 4. 每日挑戰（給大人，也給孩子回來玩的理由）

適合的遊戲（優先G003顏色實驗室這類解謎）加入每日挑戰：全球同一題，以日期為亂數種子、離線也能產生，結算可分享。不記連續天數、漏玩沒有懲罰。

### 5. 親子同玩模式

除了G019，其他適合的遊戲加入同裝置輪流模式（大人與小孩輪流操作、各自記分或合作過關）。免帳號、免連線。

### 6. G001完美疊塔兒童模式

現有難度以成人反應速度為準，6px的Perfect判定對小朋友太嚴。加入兒童模式：方塊移動速度約降30%、Perfect與最小重疊判定放寬，可在開始畫面切換並記住選擇。兒童模式的最佳紀錄與一般模式分開保存。難度調整與驗收測試另見`~/Documents/chatgpt/project_status/docs/2026-10-25-perfect-stack-tuning/`。

### 7. 下一步開發順序

G003完成後，建議先做：

1. 一款學齡前也能玩的創作類（候選G018雲朵捏捏樂），驗證「主要給小朋友」的定位。
2. 一款親子同玩遊戲（候選G019雙人小島任務，或替其他遊戲加輪流模式）。

現有G001～G003都需要閱讀或較快的反應，還沒涵蓋這兩類玩家。

## 本地模型使用決定

本機已安裝Ollama與`gpt-oss:20b`。2026-10-25用短企劃提示試跑，冷啟動超過50秒仍未產出，因此這輪直接由人工檢視分類並完成企劃。日後可在模型已啟動時用於批次發想關卡草稿或檢查文案重複度；規則正確性、適齡性、母語用法與上線品質仍由程式測試及實際玩家驗收。遊戲執行時不依賴本地或雲端模型。
