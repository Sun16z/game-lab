# G001重設計預覽：天空建築工坊

第一款先供Justin試玩評估，PR驗證完成後保留預覽，不自動合併。

## 方向

以有窗戶的小屋取代抽象積木。孩子從屋頂城市往上搭建，10層進入雲海工坊、25層到星空基地；背景使用有限的向量形狀、熱氣球、浮島與戴安全帽的陪玩角色。深色星空與白天有明確層次差異。

色盤：天空`#91ced7`、陶土`#c56747`、琥珀`#e8c574`、植栽`#9ac2ad`、油墨`#284d61`。桌機採左舞台／右工坊操作單，手機維持直向舞台；資料字體使用系統等寬數字，標題使用Avenir Next／Noto Sans TC重字重。

## 玩法與操作

- 既有交接驗收的難度曲線、兒童模式、連擊修復與本機進度繼續使用。
- 增加目標投影與兩側對齊參考線，降低理解操作的門檻。
- 可點舞台或「放下小屋」大按鈕；暫停與結算時不顯示放下按鈕。
- 目的地進度條與10／25層抵達回饋，讓短期目標清楚。
- 完美落點沿用粒子、音階與短暫震動，減少動態設定停用裝飾位移。
- 開場保留9語玩中學資訊，新增9語三連完美修復提示。

## 技能參考的取捨

採用前次評估中的可預測規則、玩中教學、分層手感診斷、HUD安全區與跨裝置檢查等方法。使用本機frontend-design規範執行設計。未安裝外部Skill、CLI或額外依賴；素材由本專案的SVG與Phaser向量繪製。

## 驗證

高塔情境在本機瀏覽器以暫時測試攔截取得場景實例，調整輸入時間後透過正式「放下小屋」按鈕觸發10／25層；此攔截不寫入產品。另實測暫停、繼續、結果、重玩、手機與800×600版面，並檢查9語及RTL。預覽截圖存於該PR的QA資料夾。
