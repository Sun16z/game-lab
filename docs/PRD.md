# Game Lab PRD

來源：[AI遊戲開發可行性分析分享討論串](https://chatgpt.com/share/6add56b5-4028-83e8-a8f9-61190f38fb86)，2026-10-25讀取。這份文件記錄開發方向；討論串中的30天與KPI數字是待驗證目標，並非已完成成果。

## 產品目標

建立以20款不同玩法為目標的免費HTML5遊戲網站；目前G001、G002可玩，其餘為企劃。前五款用於驗證手感、答題、排序、跑酷及路線熟練等不同重玩動機。手機觸控優先，也支援鍵盤。每局約30至120秒。首發先用匿名、最少量資料；不收集學童姓名、學校或班級。廣告、帳號、正式分析後端與平台投稿需另行設計和驗證。

## G001：完美疊塔

- 邏輯畫布寬480px；初始方塊寬220px，初速140px/s，每5層加速10%。
- 點擊、觸控或Space放置。偏移部分切除；中心誤差≤6px為Perfect，保留完整寬度。
- 每層100分；Perfect加50分。連續3次Perfect後另加50分，逐次增加，額外Combo分上限200分。
- 每第3次連續Perfect修復最多6px寬度，修復後不超過220px；這是2026-10-25的可玩性小實驗，需由玩家觀察驗證是否提升重玩意願。
- 中心誤差≤1px另給神準獎勵75分；與原本≤6px的Perfect區別。連擊加分、寬度修復及加速規則維持可預測。
- 無重疊或剩餘寬度<18px即結束。結算顯示層數、最佳層數及差距，可立即重玩。
- 結算以「分享成績，挑戰朋友」為主要動作；圖卡與原生分享文字含本局層數和挑戰句，另可下載PNG、複製帶目前語言的遊戲連結及立即重玩。圖片在裝置上產生，不需後端。
- 放置時顯示偏差像素；被切下的部分短暫落下，塔輕微回彈，Perfect有亮光。遊玩中顯示連擊進度及距離個人最佳的層數；減少動態效果設定會關閉裝飾動畫。
- 方塊落下有微幅鏡頭震動，Perfect會有短暫火花；第10層進入天空、第25層進入星空。音效開啟時，放置音依層數構成短音階，神準有更高的三音提示；音效仍由玩家開關。
- 累積10／30層分別解鎖霓虹／星際主題，可在準備與結算畫面選擇。單局10層、連續5次Perfect及單局100層各有一個本機成就；只使用本機儲存。
- 每局配色可依Seed改變；Seed不可影響物理規則。記錄分數及最高紀錄，無網路仍能玩。

## 其他遊戲首版規則摘要

- G002：2至9乘法共64道算式，4個不重複選項，90秒；每5隻普通怪出現3血Boss，錯題在下局適度複習。答案由確定性程式產生。結算可產生本機PNG圖卡及附帶打倒數的挑戰連結，朋友開啟後能直接接受挑戰。
- G003：每管容量4，起始3色5管，點選來源與目標倒水；可無限撤銷；首發30個固定Seed且經求解器驗證有解的關卡。
- G004：3條跑道，0至100非負加減法，每5至7秒出題；3護盾，90秒或耗盡結束；換道約0.15秒。
- G005：低多邊形3D雪道，固定90秒，速度12至22m/s；3組固定Seed，支援轉向、跳躍、旗門與撞擊後繼續滑行。

## 共用架構

- `apps/portal`：Next.js網站入口與日後可索引的遊戲介紹頁。
- `games/*`：各遊戲獨立開發與靜態匯出，Portal只負責嵌入，不能是遊戲執行的必要依賴。
- `packages/game-core`：Run狀態與規則合約。
- `packages/game-storage`：本機最佳成績，儲存失敗時遊戲仍可繼續。
- `packages/game-analytics`：事件Schema與可替換傳送介面；正式蒐集須先完成隱私與同意設計。
- `packages/platform-adapters`：自有站與未來外部平台的適配介面。首版廣告只提供Mock介面。
- `packages/locale-voice`：跨遊戲共用的連擊稱讚短句；候選及地區／審核資料保存在`knowledge/locale-voice`，遊戲包只包含短句。
- `packages/game-share`：各遊戲結算可共用的本機成績圖卡、圖片分享／下載及連結複製功能。

Run由`READY → PLAYING → RESULT`；`PAUSED`、`ERROR`可獨立切換。重玩必須產生新的`run_id`，不以整頁重整替代。事件包含`event_id`、`game_id`、`run_id`、`session_id`、ISO時間戳與版本。`retry_click`和下一局的`game_start`分開計數。

## 衡量與發行

主要指標：同次造訪重玩率＝同一工作階段至少開始第二局的工作階段數／至少開始第一局的工作階段數。首輪35%是討論串提出的決策門檻，須待真實樣本驗證。D1/D7使用台灣日曆日，僅在有合適同意與識別覆蓋率時評估。

每款遊戲需通過開始、遊玩、結束、重玩、手機觸控、鍵盤、暫停、本機儲存失敗降級及獨立包測試。G001與G002已公開部署到GitHub Pages供手機測試；廣告與外部平台投稿尚未執行。

全球／好友排行榜先列為下一階段：需選擇後端、限制匿名提交頻率、驗證不合理成績、設計資料保存期限與兒童隱私，再做成本與壓力測試。風力與不規則形狀會改變點擊時機和可讀性，待玩家測試現有加速與神準規則後再決定是否加入。
