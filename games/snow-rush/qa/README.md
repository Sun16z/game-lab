# 雪山極速90秒驗收

- 375×812：真實瀏覽器觸控按住右鍵後x由0移至0.75，點跳躍後跳躍計時大於0；90秒自然結算，再玩按鈕在首屏，重玩建立新run。
- 800×600：方向鍵、空白鍵、90秒結算與重玩；本機PNG分享替身收到有效圖卡與含語言、雪道、目標分數的連結。系統原生分享面板仍需實機確認。
- 九種語言在375×812開始、暫停、恢復及水平溢出檢查通過；阿拉伯介面RTL。母語翻譯尚需審閱。
- 題材為固定種子Canvas透視雪道，沒有3D引擎；碰撞減速後可繼續，分數為旗門×100減碰撞×20，最低0。
- 以既有授權音源搭配共用音訊模組；無帳號或後端，進度和圖卡只在裝置產生。

## 3D角色試作

朵朵與栗栗可在開始前選擇，遊戲內由本機產生的WebGL幾何角色呈現，具轉向傾斜、跳躍及手臂擺動。造型是簡化原型，尚非精緻角色模型；雪道仍是Canvas透視。WebGL不可用或context遺失時回退到所選角色圖片以保留可玩性。

375×812朵朵與800×600栗栗實際畫面無錯誤及水平溢出；觸控跳躍、暫停及恢復通過。WebGL停用時選栗栗仍可遊玩。375×812桌面瀏覽器CPU降速4倍三秒觀察180幀、平均16.66ms、無超過50ms長任務；不能代替實體手機測試。圖見3d-dodo.png與3d-lili.png。

## 雪山極速調整（2026-11-02）

起步速度28、最高42；轉向速度與旗門間隔同步調整，三條雪道的90秒自動避障測試通過。雪道增加多層山景、纜車及隨距離移動的風雪線條；遊戲依然是Canvas透視雪道與WebGL角色。配樂改為遊戲原創32秒輕快循環，沿用共用音量與靜音設定。瀏覽器確認按下開始後新音檔成功進入播放；實體裝置揚聲器的音色仍待實機驗證。
