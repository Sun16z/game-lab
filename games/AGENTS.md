# Game-specific skill selection

Before modifying a game, consult `docs/GAME_SKILL_ROUTING.md` at the repository root and read the relevant locally vendored `SKILL.md` files for the actual task and engine. Apply only relevant guidance; the root `AGENTS.md`, child-safety rules, user instructions, and this project's existing architecture take precedence. Never assume an engine or install one from a skill recommendation. Inspect any third-party script and its dependencies before running it.
