## 更新：專注優先規格

新版375×812截圖：`classic-v2.png`、`neon-v2.png`、`cosmos-v2.png`；連續操作錄影：`focus-v2.webm`。遊戲中每幀繪製後會清除特效裁切線以上的像素，測試驗證該區域的色彩和光照均為零；已將25fps錄影依時間順序拆成逐格操作區接觸表，檢查移動方塊與特效位置；點擊反應時間的樣本見下。

新版reduced-motion三連擊後未配置像素畫布、0次繪製。結算新紀錄確認觸發彩帶，見`record-v2.png`。新版Chrome DevTools Protocol錄製：375×812、CPU 4×，結算彩帶期間記錄15098個trace事件、無超過50ms的RunTask；203個動畫間隔平均16.66ms、最大23ms。瀏覽器合成點擊同步處理時間：低動態3次為3.1、2.9、2.1ms，特效開啟為3.2、3.0、3.1ms；樣本少且非實機，不能證明反應時間完全不變。測試對整個0.8秒的逐次特效渲染驗證裁切線以上色彩與光照均為零。已按25fps逐格檢查錄影的操作區域；實體手機和更多玩家的反應仍需觀察。
